# アイコン

いま入っているのは仮のアイコン（令呪の紋様）です。同じファイル名・同じサイズで上書きすれば差し替わります。

| ファイル | サイズ | 使われるところ |
|---|---|---|
| `icon-192.png` | 192×192 | ホーム画面・アプリ一覧（Android・パソコン） |
| `icon-512.png` | 512×512 | インストール時の画面・起動画面（Android） |
| `icon-maskable-512.png` | 512×512 | 丸や角丸に切り抜かれるアイコン（Android）。**大事な絵柄は中央の直径8割の円の中に**収め、背景は端まで塗る |
| `apple-touch-icon.png` | 180×180 | iPhone・iPad のホーム画面。**透明にしない**（透明部分は黒くなる）。角は自動で丸くなるので、四角のままでよい |
| `favicon-32.png` | 32×32 | ブラウザのタブ |
| `icon.svg` | 自由（正方形） | ブラウザのタブ（対応ブラウザ）。仮アイコンの元の絵。使わないなら消して、`index.html`・`roster.html`・`manifest.webmanifest` から行を外す |

- 形式はPNG（`icon.svg` だけSVG）。背景色は `#050d22`（ゲームの一番奥の色）にそろえると、起動画面となじみます
- アプリの名前・色は `manifest.webmanifest`（`name`・`short_name`・`background_color`・`theme_color`）
- 差し替えたあと、`sw.js` の `VERSION` を1つ上げる（`v1` → `v2`）と、すでにインストールした人の端末でも新しいアイコンが保存し直されます。ホーム画面のアイコン自体は、OSによっては追加し直すまで変わりません

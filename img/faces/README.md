# 顔グラフィック（img/faces/）

サーヴァントの顔の画像を置くと、ゲームで表示されます。**無い英霊がほとんどで構いません**（無ければ今までどおりクラスのアイコンのまま）。

- **ファイル名**：ゲームで使う真名そのまま。例：`アルトリア・ペンドラゴン.webp`
  - 同じ真名の別の騎（別のページ・別のクラスから取り込んだもの）がいるときは、あとから入れた方に印（key）が付いています。その騎は **真名#key.webp**（例：`アルトリア・ペンドラゴン#abc12.webp`）に置いてください。key の無い騎の顔は借りません（画像が無ければクラスのアイコンのまま）
  - key はリストツール（roster.html）の一覧（名前の横の `#…`）と、各騎の詳細で確かめられます。詳細の顔グラフィックの欄に、置くべきファイル名がそのまま出ます
  - リストツールで真名を変えた英霊は、変えたあとの真名
  - 形式は `.webp`（おすすめ）・`.png`・`.jpg` のどれか。同じ名前で複数あれば webp → png → jpg の順に使う
- **大きさ**：正方形、256×256 ピクセル程度（顔が真ん中に来るように切り抜く）。表示は 20〜112 ピクセルなので、大きすぎる画像は読み込みが遅くなるだけ
- **置き方**：GitHub のこのフォルダで「Add file → Upload files」。置いたら、数分でゲームに反映されます

## 表示される場所

真名を知られないように、**自分が引いたサーヴァント**と、**真名が分かったサーヴァント**だけに出ます。

- 左の「Servant」の欄（大きめ）と、開戦時の「あなたのサーヴァント」
- 右の陣営の一覧（クラスのアイコンの代わり）
- 解説の窓（右上）
- 結末の表（クラスのアイコンの代わり）

リストツール（roster.html）では、各騎の詳細の上に、画像があるかどうかと置くべきファイル名が出ます。

# 聖杯戦争 観戦記

七騎のサーヴァントと七人のマスターが、ひとつの街で最後の一騎になるまで戦う（最長30日。10〜100日で変えられる）聖杯戦争シミュレーションです。プレイヤーは一陣営のマスターとして、日々の方針と要所の決断を選びます（すべておまかせにもできます）。サーヴァントは kagemiya@ふたば の設定をもとにした二次創作です。

> このページは**プレイヤー向けの説明**です。データの追加・管理、仕組みの詳細、数値の調整は [開発者マニュアル](docs/DEVELOPER.md)、AIエージェント向けの英語の仕様書は [AGENTS.md](AGENTS.md) を見てください。

- **申請フォーム**（`submit.html`）… 新しい英霊の申請や、英霊の調整の希望を管理者に届ける

- **強さランキング**（`ranking.html`）… すべての英霊の強さの一覧。真名が分かってしまうので、ゲームの最初の画面ではいちばん下にだけリンクがあります（戦争の中で推し量りたい人は開かないでください）

## 遊び方の流れ

1. 最初の画面で[開戦の設定](#開戦の設定)を選んで「開戦する」
2. マスターとして始めると、記録が流れ出す前に**案内が3枚**出ます（マスターの紹介・サーヴァントの評価・最初の方針）
3. あとは日々の記録が流れていきます。**方針**はいつでも変えられ、要所では**大きな決断**で止まって選びます（「決断をおまかせ」で止まらずに進めることもできます）
4. 最後の一騎が決まる（または期限が来る）と結末の画面になり、**画像にして保存**したり、これまでの記録として残したりできます

## 開戦の設定

- **立場**：ひとつの陣営のマスター／すべてを知る観測者
- **進む速さ**：ゆっくり・ふつう・はやい・とても速い（8倍）。観戦中は上の 1×〜16× で変えられる
- **一言を残す**：節目で聞く（既定）／聞かない。前回選んだものが残る（[一言を残す](#一言を残す)）
- **戦争の長さ**：10〜100日（既定は30日）。短いほど決着がつかないまま終わりやすい（10日だと多くは引き分け）。長くしても、ふつうは最後の一騎が決まった時点で終わる
- **七騎の選び方**：クラスごとに一騎（既定）／全騎から均等に。「全騎から均等に」では、クラスを気にせずリストの全員から同じ確率で七騎が選ばれ、同じクラスが何騎も並ぶことがある（（一）（二）と番号が付く）
- **エクストラクラス**：ときどき加わる（既定）／加えない。加えないと、ルーラーなどエクストラクラスの英霊は、代役としても呼ばれない
- **シード**：同じシード・同じデータ・同じ選択なら、同じ戦争になる。空欄なら毎回ちがう戦争

長さ・選び方・エクストラクラスは前回選んだものが残ります。どれも戦争の展開を変えるので、共有リンク、中断中の戦争、これまでの記録にも一緒に保存され、再現するときはそれが使われます。

マスターの年齢は16〜46歳で、原作に倣って10代・20代がやや多めに出ます。

### 参戦サーヴァントの設定

最初の画面のいちばん下（強さランキングのリンクの下）に、折りたたんだ「参戦サーヴァントの設定」があります。戦争に呼ばれるサーヴァントを絞る機能です。真名がすべて見えてしまううえ、顔ぶれを選ぶとゲームのコンセプト（誰が来るか分からない）に反するので、目立たない場所に置いています。

- 全体の「全選択」「全解除」と、クラスごとの「全選択」「全解除」、騎ごとのチェックで選びます（既定は全員参戦）
- 外した騎は、七騎の抽選にも、クラスの代役にも呼ばれません。クラスの全員を外すと、その席は別のクラスの英霊が代役で埋めます
- 参戦するのが七騎に満たないと開戦できません
- 設定はこのブラウザに残ります。何も外さなければ、今までと同じ戦争になります
- 外した騎は戦争の展開を変えるので、共有リンク、中断中の戦争、これまでの記録にその戦争の分が保存され、再現するときはそれが使われます。共有リンクで開いたときは、保存した設定ではなくリンクの設定になります

## マスターとして始める

元にした「80億分の1」と同じく、ふだんは**方針**だけを決め、要所で**大きな決断**をします。

マスターとして始めると、記録が流れ出す前に案内が3枚出ます。

1. **マスターの紹介**：名前・素性・出自・性格・願い・触媒・能力値（魔力量・魔術・体力・精神・幸運）。名前はくじで決まったものが入っていて、ここで自分で付けられます（20字まで。空欄でくじの名前に戻る。前回付けた名前も選べる）。名前は文面にしか出ないので、付けても戦争の展開は変わりません。共有リンク・中断・記録にも残ります
2. **サーヴァントの評価**：リストの全騎と1対1で戦った場合の平均勝率から、S〜Eの6段階で評価（上位10%がS、25%までA、45%までB、65%までC、85%までD、残りがE。Fateのランクに合わせてEまで。EXには「評価不能」の意味もあるので、最高はS）。基礎戦闘力・宝具の威力の順位、長所と短所も出ます。今回の顔ぶれとの相性ではなく、その英霊そのものの強さの目安です
3. **最初の方針**：一日目の動き方を選ぶ（★おすすめ付き）。選ぶまで一日目は始まりません
   - おすすめは、同じ戦争を方針だけ変えて全自動で戦わせ、方針を変えずに最後まで戦ったときに最も勝ちやすかったものです（サーヴァントの評価ごと）。今のデータでは、評価S・Aは「おまかせ」、B〜Dは「休養」、Eは「潜伏」（Eはどの方針でもほとんど勝てないが、潜伏がいちばん長く残れる）。おまかせは陣営の戦略に沿って、その晩の霊基や相手との力の差を見て出撃を決めるので、方針で毎晩の動きを固定するより勝ちやすい

共有されたリンク（決断・方針の記録つき）で再現するときは、案内を出さずにそのまま進みます。

パソコンでは、方針の欄を見出しの「たたむ」で一行に格納できます（スマホの「方針：○○ ▾」と同じ）。たたんだ状態はブラウザに残ります。

- **方針**（いつでも変えられる・次の朝から反映）：おまかせ／攻め／守り／偵察／休養／潜伏／交渉。昼の行動、夜に出撃するか、戦い方（全力・様子見・すぐ退く）が決まる。おまかせは陣営の戦略（開戦時にサーヴァントに合わせて決まる）どおりに動く
- **大きな決断**（止まって選ぶ）
  - 作戦会議（5日ごと）：状況に合う選択肢が最大3つ出る。拠点への総攻撃、令呪による強化、拠点の移動、同盟の申し込み、同盟の破棄と奇襲、真名の推理、使い魔で拠点を探す、霊脈で力を蓄える
  - 致命傷のとき：令呪で退かせる・令呪で奮い立たせる・使わない
  - 他の陣営からの同盟の申し出、討伐令、昼の街で敵マスターを見かけたとき
  - サーヴァントを失ったとき：教会に保護を求めて最後まで見届ける／教会に保護を求めて結末まで早送り／主を失ったサーヴァントと契約する（はぐれがいるときだけ。単独行動の日数だけ現界している）／他のマスターから令呪を奪う（成功はごくまれ。失敗すると多くは命を落とす）。運が悪いと、サーヴァントが消えたその場でマスターも命を落とす
  - マスターが死んだとき：ゲームオーバー。見届けるか早送りするかを選ぶ

「決断をおまかせ」を押すと、以後は止まらずに進みます。方針の変化と決断の内容は共有リンクに残るので、リンクを共有すると同じ戦争を再現できます。

### 真名の推理

教会は真名を教えません。戦った相手の戦い方、宝具の気配、偵察で得たものは**手がかり**として貯まり（陣営一覧に「手がかりN」と出る）、作戦会議の「真名を推理する」で当てられる見込みが上がります。外れても手がかりは1つ増えます。宝具を真名ごと聞いたり、偵察で見抜いたりすれば推理なしで分かります。

自分のサーヴァントと、真名が分かったサーヴァントは、解説を読めます（左の「解説と資料を見る」、陣営一覧のⓘ、結末の表の真名）。Wikiの解説の冒頭と、生存曲線、Wikipedia（真名・元ネタで検索）と kagemiya@ふたば のページへのリンクが出ます。まだ真名を知らない相手のものは出ません。

### マスターの性格

マスターには性格があり、戦略の選び方・出撃・撤退・同盟・令呪・マスター狙い・終盤の裏切りなどが偏ります（冷徹な合理主義者、誇り高い魔術師、慎重な策略家、好戦的な戦闘狂、情に厚いお人好し、臆病な素人、狡猾な暗殺者、野心家）。他のマスターの性格は最初は分からず、戦ったあとに見えてくることがあります。

### 戦闘中のマスター殺し

戦闘の打ち合いで押し勝った側の刃が、まれに相手マスターに届きます。マスター狙いのスキル（気配遮断など）や暗殺者気質のマスターほど起きやすく、マスター防御・自分の工房で守られます。令呪で防げることもあります。

## 記録と結末の画面

記録はふだん新しいものだけを表示し（パソコン10件・スマホ5件）、「すべての記録を見る」で枠の中をスクロールして全部読めます。

記録の上のボタンで絞り込めます。

- **★ ハイライト**：勝敗が決まったとき・令呪・同盟と裏切り・討伐令・因縁の再会・真名の看破・結末など大きな出来事。宝具を解放しただけでは入りません。戦いで脱落した記録は、とどめと決め手と一緒に書かれます（「〇〇の宝具『…』が勝敗を決定づけた。△△は消滅した。」「宝具『…』で追い詰めた〇〇が、とどめを刺した。」「〇〇がとどめを刺した。」）
- **自陣営**：あなたの陣営が関わった記録だけ
- **CSVで保存**：ここまでに表示された記録をCSVファイルで保存（Excelで開ける。まだ見ていない先の展開は含まない）

結末の画面には次のものが出ます。

- **他の六陣営の目的と歩み**（観測者なら七陣営）：マスターの願い・英霊の願い・戦略から見た戦い方の狙い・戦った回数と倒した相手・最も多く刃を交えた相手・結末と、その陣営が主役の大きな出来事
- **絆の推移**：あなたの陣営の絆を日ごとに線で。サーヴァントを失ってからは点線。なぞると日ごとの値が出ます
- **決断の一覧**：何日目に何を問われ、何を選んだか（おまかせも含む）と、方針の移り変わり
- ハイライトを古い順に並べた「振り返り」と、「自陣営の記録を見る」「記録をCSVで保存」のボタン

## 中断と続きから・これまでの記録

- **中断**：観戦中の「中断」で最初の画面に戻ると、その位置が保存されます。ページを閉じたり再読み込みしたりしても、1日の始まりと決断のたびに保存されています。最初の画面の「**続きから**」で、中断したところから再開します（中断中の戦争は1つだけ。新しく開戦すると上書き）。決断の画面が出ているときは「いったん下ろす」で下ろしてから中断します
- **これまでの聖杯戦争**：終わった戦争は新しいものから10件まで最初の画面に残ります。「最初から見る」「結末だけ見る」で再生、「リンクをコピー」で共有用のURL。同じ戦争を再生し直しても記録は増えません
- **書き出し・読み込み**：「記録を書き出す」で記録と中断中の戦争をJSONファイルにし、別の端末やブラウザで「記録を読み込む」と取り込めます（同じ記録は重ならず、10件を超えた古いものは外れる）。「すべて消す」は元に戻せません
- 保存するのはシード・決断・方針だけで、再開や再生のたびに同じ戦争を組み直します。リストが変わっていると同じ展開にならないため、そのときは確認が出ます
- **記録の整理**：記録ごとに「☆ 保護する」と「消す」があります。保護した記録は10件の数に含まれず、外すか消すまで残ります（30件まで）。「すべて消す」は保護したものも消します
- 記録と中断中の戦争は、このブラウザにだけ保存されます。別の端末へ移すときは、書き出したファイルを移した先で読み込んでください

## 一言を残す

80億分の1の「思いを残す」に倣い、マスターとして節目に一言を残せます。開戦の設定の「一言を残す」を「聞かない」にするか、問いの画面の「これからは聞かない」で止められます。

- 聞くのは、初めての戦いのあと・折り返し（戦争の長さの半分）・自分のサーヴァントを失ったとき・終幕（結末を出す前）。同じ日に節目が重なったら一番大きなもの1つだけを、次の日に移る前に聞きます。残さずに「やめておく」もできます
- 残した言葉は記録の欄にその位置で出て（ハイライトと自陣営にも入る）、結末の「あなたが残した言葉」、これまでの記録の一覧、結末の画像に並びます
- 結末には、サーヴァントの最後の一言も出ます（Wikiのセリフから。勝てば「勝利」「聖杯について」、消えていれば「戦闘不能」「消滅」など。選び方はシードで決まる）
- 言葉は中断の保存と記録に入ります。共有リンクには入らず、記録の再生や共有リンクの再現では聞かれません

## 画像にする

戦争が終わったら、結末の「画像にする」でPNG画像を作れます（ブラウザの中で描くので、サーバーは使いません）。3つの見本が並ぶので、選んでから保存します。

- **結末のまとめ**：勝者、あなたの陣営の歩み、絆、サーヴァントの最後の一言とあなたの一言、七陣営の結末、シード
- **サーヴァントの評価**：呼んだ英霊の開戦時の評価（S〜E・平均勝率・基礎戦闘力・宝具の威力・ステータス・長所と短所）と生存曲線
- **両方をつなげた一枚**：結末のまとめの下に、サーヴァントの評価をつなげたもの
- 選んだ画像は「保存する」でダウンロード、共有できる端末（スマホなど）では「共有する」も出ます。「← 選び直す」でほかの画像に戻れます
- 観測者として見た戦争は、結末のまとめだけです

## 戦争の流れ

1. **開幕**：リストから七騎が選ばれ（既定ではクラスごとに一騎）、マスターが抽選される。プレイヤーの陣営がひとつ決まる
2. **昼**：各陣営が行動を選ぶ。偵察（拠点・真名を探る）、工房強化、休養、同盟交渉、潜伏。狂化などで制御が効かないと勝手にうろつく。夕方に維持魔力を払う（バーサーカーは重い。休養・潜伏の日は霊体化して節約）。**足りない分はマスターの生命力から吸い上げ**、マスターが倒れかけると令呪一画を魔力に換えてしのぎ、令呪も無ければマスターが力尽きる
3. **夜**：出撃するか籠もるかを決める。出撃側は索敵と相手の隠密で遭遇を判定し、相手の拠点なら拠点側に陣地・工房の補正が付く。気配を消せるサーヴァントはマスターを奇襲することがある
4. **戦闘**：最大4回の打ち合い。戦闘力（ステータスの重み付き平均×スキル効果）を比べ、押し勝った側が傷を与える。押し負けた側も、戦闘力が拮抗しているほど大きな傷を返す。宝具・特攻・魅了・先手・クリティカルヒット・防御無視・即死・致命傷耐性・撤退と逃走阻止・令呪での離脱・作っておいた道具などが絡む。宝具を使うと真名がばれやすい。戦いにも魔力を使い、バーサーカー（と制御困難の強い英霊）は魔力が尽きても止まらず、魔力を顧みずに宝具を放つ
   - **状態異常**：毒（打ち合いのたびと翌日に霊基を削る。毒では倒れない）、スタン（その打ち合いは宝具を使えず、戦闘力が半分）、混乱（戦闘力が下がり、自分を傷つけることもある）、宝具封印（その戦いの間、宝具を使えない）。状態異常耐性・精神耐性・耐久・マスターの精神で防げる
   - **弱体化**：精神への干渉（威圧・恐怖・幻惑など）と肉体への干渉（呪い・衰え・重圧など）があり、それぞれ精神耐性・マスターの精神、耐久・対魔力で防ぐ。「衰弱」は押し勝つたびに相手の戦闘力を少しずつ削り、戦いが終わっても残って毎朝少しずつ抜ける
5. **同盟**：同盟は三者まで組める。同盟相手が戦っている夜に**加勢に来る**ことがあり、そろって同じ敵を狙う共同作戦を立てることもある。毎朝、魔力の乏しい味方に余裕のある味方が魔力を分け、治療のスキルを持つ英霊が味方の傷を手当てする。ほかより多く討っている陣営が現れると、ほかの陣営は手を組みやすくなる（包囲網）。残り4騎で裏切りが起き、3騎で同盟は解ける
6. **脱落**：サーヴァントが消滅するとマスターは教会へ（プレイヤーは決断で選ぶ）。マスターが倒れたサーヴァントは単独行動の日数だけ残り、脱落したマスターと再契約することもある
7. **終幕**：最後の1騎が聖杯を手にする。決着しなければ引き分け。最後の二騎が相討ちになったとき（押し勝った側も深手で倒れることがある）や、最後に残った1騎がマスターを失っていて単独行動でも現界を保てないときは、聖杯を手にする者のいない**全滅**で終わる（単独行動の日数が残っていれば、マスターなしで聖杯を手にする）

同じシード・同じデータなら同じ戦争になります（共有リンクのシードで再現できます）。データが変わると同じシードでも別の戦争になります。数値や細かい規則は[開発者マニュアル](docs/DEVELOPER.md#戦争の進み方jsenginejs)にあります。

## ステータスの解説と役割

ステータスや能力値にマウスを重ねる（スマホはタップ、キーボードはTabで移る）と、それが戦いの何に効くかの短い解説が出ます。

- サーヴァント：筋力・耐久・敏捷・魔力・幸運・宝具（左の欄と、開戦時の評価）。クラスで重みが変わる場合はそれも出ます
- 状態：霊基・魔力・絆・工房・令呪（左の欄、スマホの上の帯、令呪の紋様）
- マスター：魔力量・魔術・体力・精神・幸運（開戦時の紹介）
- 開戦時の評価：平均勝率・基礎戦闘力・宝具の威力

宝具を除くどのステータスも、戦闘力（重み付きの平均）に関わるほか、それぞれ別の場面に効きます。

| ステータス | 効く場面 |
|---|---|
| 筋力 | 打ち勝ったときに与える傷が深くなる |
| 耐久 | 受ける傷が浅くなり、致命傷で踏みとどまりやすい |
| 敏捷 | 撤退で逃げ切る・逃げる敵に追いすがる、夜に敵を捉える・捉えられにくい |
| 魔力 | 宝具の威力が増し、宝具発動に要する魔力が減る。魔力による攻撃は、対魔力による影響を受けやすい |
| 幸運 | クリティカルヒットが出やすく、即死を免れやすく、致命傷でも命拾いしやすい |
| 宝具 | 宝具そのものの評価。戦闘には使わない（宝具の強さは宝具それぞれのランクと種別、そして魔力で決まる） |
| マスターの魔力量 | 魔力の蓄えと毎日の戻り |
| マスターの魔術 | 工房づくり・偵察がうまくいきやすい、戦いでのわずかな援護（ほかに真名の推理・使い魔） |
| マスターの体力 | 刃や奇襲が届いても生き延びやすい |
| マスターの精神 | 令呪が揺らがず、奮い立たせる令呪の力が増す。心が弱いと令呪が届かないことがある。サーヴァントが魅了や弱体化に呑まれにくく、制御の難しい英霊を抑えやすい |
| マスターの幸運 | 夜に見つかりにくい、マスターを狙う刃や奇襲をかわしやすい |

マスターの能力値はサーヴァントのステータスより小さめに効きます。速さで振り切った・頑強な霊基で踏みとどまった・心が揺らいで令呪が届かなかった、などは記録にも出ます。

## 日常と街の出来事

- **日常**（自陣営で1日40%）：食事（Wikiの好きなもの）、夜更けの会話（セリフの「会話」）、マスターが見るサーヴァントの過去の夢（解説の一文）、苦手なもの、聖杯への願い、外出、マスター自身の一日、稽古、生前の話（人物・性格の一文）、傷の手当て（霊基が減っているとき）、すれ違い、見張り、星を見上げる夜。**絆**が深まり（すれ違いは少し浅くなる）、令呪の効き・撤退・踏みとどまり・制御のしやすさが少し良くなる
- **街の出来事**（1日25%）：霊脈の活性化、霊脈の乱れ（どの陣営も魔力が減る）、雨の夜（戦場が水辺扱い）、満月、聖杯の鳴動（どの陣営も出撃しやすい）、夜霧（互いを見つけにくい）、監督役の巡回（どの陣営も出撃を控える）、祭り（その夜は誰も動けない）、使い魔、宝具の目撃と監督役の警告、討伐令（討った陣営に追加の令呪）、街の噂（まだ拠点の分からない敵の噂。たどるか聞き流すかを選ぶ）
- **因縁**：Wikiの「因縁キャラ」に同じ戦争のサーヴァントの名前があれば、出会ったときに因縁の一文が出て、互いを狙いやすくなる

## 強さランキングと生存曲線

**強さランキング**（`ranking.html`）は、すべての英霊の強さを見比べるページです。真名が分かってしまう（戦争の中で推し量る楽しみが減る）ので、ゲームの最初の画面では、開戦するボタンや記録よりも下、いちばん下の説明の中にだけリンクを置いています。

- 列：評価（S〜E）・優勝率（出た戦争のうち勝ち残った割合と出た回数）・生存（半分が脱落するまでの日数。「最後まで」は半分以上が最後の日まで残った）・平均勝率（全騎と1対1）・戦闘力・宝具の威力・攻め／守り／粘り／隠密／索敵（ステータスとスキル・宝具の効果を合わせた得意分野。リストの中での順位で S〜E）
- 見出しを押すと並べ替え、真名を押すと、省略されていない真名・ステータス・目立つ効果・宝具が開きます。クラスで絞ったり、真名・元ネタで探したりできます

**生存曲線**は、サーヴァントの解説（左の「解説と資料を見る」、陣営一覧のⓘ、開戦の案内）に出ます。その英霊が何日目まで生き残れるかの曲線です。今回の戦争ではなく、リストから毎回ランダムに七騎を選んで全自動で戦わせたたくさんの聖杯戦争（既定の設定：30日・クラスごとに一騎・エクストラときどき）で、その英霊が呼ばれたときの総合的な見込みです。点線はリスト全体の平均です。

ランキングの優勝率や生存曲線の数字は、公開データと一緒に用意された集計から出ています。集計とデータが合っていないときは、見ている端末のブラウザで計算し直すので、数秒〜十数秒かかり、数字は少し粗くなります。開戦時の評価（S〜E）と1対1の平均勝率は、開くたびにその時のデータから計算するので、いつも最新です。

## 申請フォーム

新しい英霊の申請や、登録済みの英霊の調整の希望を、管理者に届けるためのページです（`submit.html`）。サーバーは使わず、入力はその端末の中だけで処理します。ゲームの最初の画面の下と、英霊の解説の「この英霊の調整を希望する」から開けます。

- **新しい英霊を申請**：kagemiya のページ名を入れる（Wikiに載っていればそれだけでよい）。ページのテキストを貼り付けると、ゲームがどう読み取るか（ステータス・スキルの効果・宝具が攻撃か補助か・推定になっているところ・評価 S〜E）をすぐ確かめられます。「Wikiのページと同じ内容です」に印があれば、テキストは確かめるためだけに使い、申請にはページ名だけを入れます
- **登録済みの英霊の調整を希望**：英霊を選ぶ
- どちらも、まず「**ゲームではこう判断されます**」が出ます（スキルのうち名前で分かったもの・説明から推定したもの・読み取れなかったもの、宝具が攻撃か補助か）。各スキル・宝具には効果と「**判断の理由**」（辞書にあるスキルだった／説明の言葉から推定した／攻撃の言葉があるので攻撃宝具とみなした…）が付きます
- 違っていたら、項目ごとの「**ここを直してほしい**」に文章で書けば十分です（ステータスにも欄があります）。読み取りの間違い（スキルではない行など）は「スキルではない（消してほしい）」に印を付けると、消した場合の評価がすぐ出ます。効果を自分で決めたい人は「効果を自分で指定する（くわしい人向け）」で、効果の種類と強さ・宝具の扱い（攻撃／補助）を直せ、評価・平均勝率・戦闘力・宝具の威力が「調整前 → 調整後」で出ます
- **セリフ・解説・プロフィール**：読み取った内容を、場面ごとの欄で直せます（直したところだけが申請に入る）。直すのが難しければ、それぞれの「直してほしいこと」の欄に文章で書くだけでもかまいません
- 理由・そのほか直してほしいこと・お名前・連絡先も書けます
- 届け方は3つ：**GitHub で申請する**（内容を書き込んだ Issue の画面が開く。GitHub のアカウントが要る）／**ファイルに保存**（申請の .json）／**文面をコピー**（X や Discord などで送る）。ページのテキストや書き換えたセリフが長くて Issue に入らないときは、ファイルを添付するよう案内が出ます（「GitHub で申請する」を押すとファイルも保存される）

## アプリとして使う

公開ページから、そのままアプリとしてホーム画面やパソコンに追加できます。

- Chrome・Edge（Android・パソコン）：最初の画面に「アプリとして追加する」ボタンが出ます（アドレスバーのインストールのアイコンからも可）
- iPhone・iPad：Safari の共有ボタンから「ホーム画面に追加」（最初の画面に案内が出ます）
- 一度開けば、電波のないところでも遊べます。オンラインのときは常に最新のファイルを取りに行くので、更新はすぐ反映されます
- `index.html` をダブルクリックで開いた場合は公開データを自動で読めないので、画面の案内に従ってデータのJSONを選んでください（このときはアプリとしては使えません）

## 特異点攻略（テスト版）

人理を歪める特異点に、六騎の英霊を率いて降り立ちます。特異点の名前は「炎上汚染都市 札幌」のように、三つの熟語と実在の都市で決まります。

1. 「特異点を観測する」を押すと、特異点の名前と、率いる六騎（クラスごとに一騎ずつ。どれか一つのクラスはあぶれる）が出ます。前衛に立てる三騎を選んで「レイシフトする」
2. あとは記録が流れていきます。敵サーヴァントは七騎。全員を倒すと特異点の主（ボス）が現れ、それを倒せば**人理修復 成功**です。期限（はじめは30日）を過ぎる・全滅する・マスターが倒れると失敗
3. **方針**（おまかせ・進軍・索敵・隠密・休息・陣地）はいつでも変えられ、次の朝から反映されます。索敵に成功すると敵と出会いやすくなり、隠密や幸運は悪い出来事・雑魚・夜襲を減らします
4. **令呪**は三画で、10日ごとに一画戻ります。英霊が消えかけたときに霊基を癒やす（一画）、一時停止中に霊基を癒やす・魔力を満たす（一画、次の朝に働く）、全滅したときに三画で全員を呼び戻す、の三つの使い道があります
5. 一度でも出会った敵は、一時停止中に**真名を推測**できます（1日に一度）。当たれば、その敵との戦いで有利になります
6. 前衛が倒れると、控えが順に前に出ます。倒れた英霊は消滅し、全滅のときの令呪でしか戻りません。旅の途中で、一騎だけ**はぐれサーヴァント**が力を貸してくれることもあります

味方や敵の顔ぶれは、編成の画面のいちばん下「編成を自分で決める」で選べます（真名が見えてしまいます）。サーヴァントのデータは聖杯戦争と同じです。

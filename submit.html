4. 管理者に届ける

  1. GitHub で申請する：内容を書き込んだ「Issue」の画面が開きます（GitHub のアカウントが要ります）。確かめて「Submit new issue」を押せば届きます

  3. 文面をコピー：下の文面をコピーします。X や Discord などで管理者に送れます

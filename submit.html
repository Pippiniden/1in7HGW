英霊の申請・調整の希望聖杯戦争へ →

新しい英霊をゲームに加えてほしいとき、登録済みの英霊の強さや読み取りを直してほしいときに使います。入力した内容はこの端末の中だけで処理し、どこにも自動では送りません。最後に「GitHub で申請する」「ファイルに保存」「文面をコピー」のどれかで管理者に届けてください。

公開中のリストを読み込んでいます…

1. 英霊のページ

Wikiにまだ無いとき・Wikiと違う内容で申請したいときは、下にページのテキスト（編集画面の中身）を貼り付けます。貼り付けると、ゲームがどう読み取るかをすぐ確かめられます。

1. 調整してほしい英霊

2. ゲームでの読み取りと、直してほしいところゲームがWikiの文章をどう読んだかです。違っていたら「ここを直してほしい」に書いてください

評価 S〜E はゲームの開戦時の評価と同じ式（公開中のリストの全騎と1対1で戦った平均勝率の順位）。

ステータス（空欄はWikiの値のまま。「A+」「C~A」のようにランクで）

スキル

宝具

3. セリフ・解説・プロフィール読み取った内容です。直接直すか、直してほしいことを書いてください（直したところだけが申請に入ります）

4. 理由・補足

5. 管理者に届ける

  1. GitHub で申請する：内容を書き込んだ「Issue」の画面が開きます（GitHub のアカウントが要ります）。確かめて「Submit new issue」を押せば届きます
  2. ファイルに保存：申請のファイル（.json）を保存します。管理者に送るか、Issue に添付してください
  3. 文面をコピー：下の文面をコピーします。X や Discord などで管理者に送れます

# data/incoming（アップロード置き場）

リストツール（roster.html）で書き出したファイルを、ここにそのままアップロードすると反映されます。
ファイル名は何でもかまいません（`servants (3).json` のままでよい）。何のファイルかは中身で見分けます。

1. GitHub でこのフォルダを開き、「Add file」→「Upload files」でファイルを入れて「Commit changes」
   （リストツールの「公開・保存」の「GitHub にアップロード」からも、この画面が開きます）
2. Actions の「データの反映」が動き、反映・ゲームが動くかの確認・生存曲線の集計の作り直しをして、
   **何が変わったかを本文に書いたプルリクエスト**を作ります
3. 本文の差分を確かめてマージすると公開されます（このフォルダのファイルはそのとき消えます）

| 上げるもの | 反映のしかた |
|---|---|
| 「公開用に保存」「リストをJSONで保存」のファイル | 今のリストの8割以上の騎が入っていれば、リストをまるごと置き換え（入っていない騎は外れる。本文に名前が出る）。少なければ、足す・置き換える |
| 「手直し表を保存」のファイル | overrides.json をまるごと置き換え |
| Wikiのページのテキスト（.txt） | 英霊を足す・置き換える（複数ページは `=====` だけの行で区切る） |
| 申請・記録のファイルなど | 反映せずに残します（申請はリストツールの「取り込み」で読む） |

中身は `tools/incoming.js`、差分は `tools/datadiff.js`、流れは `.github/workflows/data.yml`。
